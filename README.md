## Application

The repository root contains the Volt web apps and Telegram educational financial newsroom. For Render, the build command is `npm install` and the start command is `npm run start:newsroom`; this starts `apps/api/newsroom-server.js`. The existing `npm start` command continues to launch the Volt ride application. Render deployment configuration is in `render.yaml`; Arabic deployment and webhook setup instructions are in [`README_AR.md`](README_AR.md).
